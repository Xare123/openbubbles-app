# Native device validation adapter

This adapter is independently implemented for the dedicated authorized iPhone.
It contains no copied third-party NAC client implementation. Functional IPC
facts were checked against JJTech0130/ValidationRelay e1b74fbc92a1664dd4fafec526f59acd8f5e6425:
subsystem1200, three operation layouts in order, protocol word0x50936603,
com.apple.absd, and certificate / session-info-request / session-info exchange.
Those interface facts are not a statement that its unlicensed implementation
can be redistributed. No unlicensed Swift or generated Mach client was copied.

OBAbsintheIPC.defs is a local interface declaration with independent names;
the implementation/header must be generated by the installed Apple SDK mig.
Apple bootstrap_cmds c71d2d72f48995baaea76148f61002e5299841de parser.y/user.c
confirm waittime generates MACH_SEND_TIMEOUT and MACH_RCV_TIMEOUT. Require
those flags and the5000ms bound in generated-source qualification. Do not check
generated SDK implementation into this repository or remove its notices.

The pipeline fetches the public certificate over HTTPS, invokes native device
NAC init, performs the HTTPS session-info exchange, establishes the session and
signs empty bytes. All network requests retain system certificate validation
and reject redirects. It never accepts Apple account/password/2FA input, signs
arbitrary payloads, or substitutes the separate account qualifier. Returned
out-of-line allocations and the owned service send right are released. The
published three-operation interface supplies no explicit context-close call;
do not invent one or claim server-side context disposal was verified.

HTTP bodies are size-checked after NSURLSession completion; this is not a
streaming preallocation limit. No payload/proof/code is logged or written.
There is one serial native worker,5second finite Mach calls,8second HTTP bounds
and the caller's monotonic deadline. Actual SDK compilation, MIG wire compatibility,
system trust on this iOS version and real NAC generation remain UNQUALIFIED.
